TCP Port Scanner

A lightweight desktop tool for checking TCP ports on a host you are authorized to test. Built with Python and Tkinter, with adjustable concurrent scans and service labels.

View source on GitHub Setup instructions

Example service mappings

22 / ssh53 / domain80 / http443 / https

Labels come from the system's TCP port database; they do not fingerprint the service.

Run locally

Requires Python 3 with Tkinter. No third-party packages are needed.

python port_scanner.py

Authorized testing only

Use the scanner only on systems you own or have explicit permission to assess. Scanning may be logged or restricted by network operators.
